# Yayoo Femme — brand assets

Drop the ad-ready JPG assets here. Until they exist, the landing page shows a
premium CSS fallback (warm gradient + brand mark) via the `SafeImage`
component, so the build never breaks.

Expected files (final paths used by the app):

- hero.jpg            — hero visual (lifestyle, premium)
- guides.jpg          — guides & ebooks section
- finder-style.jpg    — Style Finder card
- finder-beauty.jpg   — Beauty Finder card
- finder-gift.jpg     — Gift Finder card
- finder-perfume.jpg  — Perfume Finder card
- finder-capsule.jpg  — Dressing Capsule card
- og.jpg              — Open Graph / social share (1200×630)
- ad-square.jpg       — square ad creative (1080×1080)
- ad-story.jpg        — story ad creative (1080×1920)

Guidelines: real lifestyle photography, warm editorial tone, no internal
screenshots, no embedded illegible text, no old branding.
